Privacy Policy

Last updated: 26 October 2026

1. Who is responsible

The operator named in the legal notice.

2. This website

This website is static. It does not use cookies, analytics, tracking or forms. The hosting provider (GitHub Pages) may process technical data such as your IP address in server logs, according to its own privacy policy.

3. The app and TikTok

The service uses TikTok's Login Kit and Content Posting API only to upload videos to the TikTok account that the user connects (in practice the service owner). The following data is processed for this purpose:

  • the TikTok display name and avatar of the connected account (shown to the account owner on the start page, not stored);
  • an access token of the connected account, kept only in the browser session (sessionStorage) and discarded when the tab is closed or the user clicks “Disconnect”;
  • the video file selected by the user, which is passed through a small server function (Cloudflare Workers) directly to TikTok and is not stored there.

The server function does not keep tokens, videos or logs of personal content. Cloudflare may process technical data such as IP addresses as a hosting provider.

The service does not collect, store, sell or share personal data of other TikTok users or viewers. Comments, likes and views remain on TikTok and are governed by TikTok's privacy policy.

4. Match data

Match data (teams, scores, scorers, tables) is publicly available sports data and contains no personal data beyond the names of professional players in a sporting context.

5. Your rights

You may request information, correction or deletion of any personal data that concerns you. Contact us via the details in the legal notice. The owner can revoke the app's access at any time in the TikTok app settings, after which the token becomes invalid.

6. Changes

This policy may be updated. The current version is always available on this page.
